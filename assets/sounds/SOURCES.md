# Click sounds

`click-1` … `click-3` are three takes of one plastic click, generated for
this app with Magnific's sound-effect generator (paid account, owned
output), then pitched up 5 semitones, high-passed at 400 Hz and cut to
about 57 ms. Mono, 44.1 kHz, 16-bit. Levels and pitch per button kind are
set in code (`src/kit/sound.rs`), not in these files.
